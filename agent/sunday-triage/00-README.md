# Sunday Source-Triage

This loop gives one worker a read-only Sunday check over already-ingested plays for one season, week, and source, stages integer honesty-QA counts in `report.md`, and stops at one human gate. It does not ingest data, mutate trusted tags or votes, freeze a week plan, contact anyone, schedule itself, dump raw feeds, or approve its own result.
